# quanttide-essay-of-meta-engineering

量潮元工程论文——工作论文。

## 概述

本仓收录元工程方向的工作论文。目前四篇，前三篇是一组：**总纲**讲哲学如何降维成代码，**形而上学**讲结构怎么长，**伦理学**讲「应当」怎么进结构。

| 文章 | 讲什么 | 位置 |
| :-- | :-- | :-- |
| 从哲学到代码 | 哲学分支 → 数学 → 可计算 → 代码的编译链；「可计算」是编译成不变式，不是量化 | [`intro/`](intro/index.md) |
| 本体论驱动的智能体 | 智能的瓶颈是结构能力而非拟合能力；五层架构、可执行本体、代价与新问题 | [`metaphysics/`](metaphysics/index.md) |
| AI 原生伦理学 | 以「人—智能体—规则系统」三元协作结构为原初行动单元，重写五个底座 | [`ethics/`](ethics/index.md) |
| 语境多元主义的范畴论范式 | 不做单一真理，找不同语境之间结构上的同构映射 | [`metaphysics/category/`](metaphysics/category/index.md) |

前三篇由对话记录整理而成：论证与判断保持原样、未加料，口吻已由对话体改为论文体；第四篇自旧札记仓移入，已按论文格式规范改写。四篇统一按论文格式组织：摘要、编号章节、结论，中文引号用「」。
