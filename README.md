# quanttide-essay-of-meta-engineering

量潮元工程札记——工作札记。

## 概述

本仓收录元工程方向的工作论文。目前三篇，是一组：**认知面**讲结构怎么长，**规范面**讲"应当"怎么进结构，**方法面**讲两者之间的翻译机制。

| 文章 | 讲什么 |
| :-- | :-- |
| [本体论驱动的智能体](ontology-driven-agent.md) | 智能的瓶颈是结构能力而非拟合能力；五层架构、可执行本体、代价与新问题 |
| [AI 原生伦理学](ai-native-ethics.md) | 以"人—智能体—规则系统"三元协作结构为原初行动单元，重写五个底座 |
| [从哲学到代码](philosophy-to-code.md) | 哲学分支 → 数学 → 可计算 → 代码的编译链；"可计算"是编译成不变式，不是量化 |

**素材出处**：三篇均整理自语境仓（`quanttide-context-of-meta-engineering`）的 `essay/` 目录下的对话记录，论证与判断保持原样、未加料；口吻已由对话体改为论文体。
