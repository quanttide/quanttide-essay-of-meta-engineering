# quanttide-essay-of-meta-engineering

量潮元工程论文——工作论文。

## 概述

本仓收录元工程方向的工作论文与札记。目前六篇，前三篇是一组：**总纲**讲哲学如何降维成代码，**形而上学**讲结构怎么长，**伦理学**讲「应当」怎么进结构；后三篇收在 `metaphysics/category/`，围绕「范畴」展开。

| 文章 | 讲什么 | 位置 |
| :-- | :-- | :-- |
| 从哲学到代码 | 哲学分支 → 数学 → 可计算 → 代码的编译链；「可计算」是编译成不变式，不是量化 | [`intro/`](intro/index.md) |
| 本体论驱动的智能体 | 智能的瓶颈是结构能力而非拟合能力；五层架构、可执行本体、代价与新问题 | [`metaphysics/`](metaphysics/index.md) |
| AI 原生伦理学 | 以「人—智能体—规则系统」三元协作结构为原初行动单元，重写五个底座 | [`ethics/`](ethics/index.md) |
| 范畴与类别 | category 一词在 meta 与 asset 两域分任范畴与类别：词源、体系规定与命名策略的三重暗合 | [`metaphysics/category/category-and-class.md`](metaphysics/category/category-and-class.md) |
| 语境多元主义的范畴论范式 | 不做单一真理，找不同语境之间结构上的同构映射 | [`metaphysics/category/contextual-pluralism.md`](metaphysics/category/contextual-pluralism.md) |
| 第二大脑压力分担模型 | 两个九宫格如何分流组织记忆的压力；日志是驱动点，AI 是执行层 | [`metaphysics/category/second-brain.md`](metaphysics/category/second-brain.md) |

前三篇由对话记录整理而成：论证与判断保持原样、未加料，口吻已由对话体改为论文体；《范畴与类别》由工作对话整理而成；《语境多元主义》自旧札记仓移入，已按论文格式规范改写；《第二大脑压力分担模型》自资产领域札记仓移入，资产中文名按《量潮标准范畴》口径更正。论文统一按论文格式组织：摘要、编号章节、结论，中文引号用「」。
